# 林偲駒分工紀錄

## 分工定位

林偲駒主要參與的專題發想、使用者流程討論與 Flask UI 方向建議。

## 具體貢獻

- 協助討論專題從原本硬體攝像頭方向，改成一般人可直接使用的瀏覽器鏡頭方案。
- 協助確認首頁與掃描頁應以「生活回收分類助手」為核心，而不是只展示技術功能。
- 協助討論使用流程：開啟鏡頭、拍照截圖、圖片自動分類、結果修正回饋。
- 協助檢查報告時可展示的使用者故事，例如學生吃完餐點後不知道垃圾分類時，可用手機拍照判斷。

## 對應專案位置

- `templates/index.html`：首頁呈現專題主題與資料狀態。
- `templates/scan.html`：鏡頭掃描與圖片自動分類流程。
- `README.md`：專題說明與小組分工。
- `PROJECT_PLAN.md`：專題動機、解決方案與系統架構。

- 補充更多使用者故事或 demo 腳本。
